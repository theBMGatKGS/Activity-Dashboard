Quick Start

  1. Daily Focus opens first. Four squares show Due Today (with the change since the previous business day), Overdue, Waiting past due and Going cold. Click a square to jump to its section. Each row has ✓ Done, Snooze and Log touch. The other views are tabs: Totals, Workload, Print sheet, Manager's sheet.
  2. Open index.html in your OneDrive Dashboard folder in Chrome or Edge (Mac: <synced folder>/Dashboard/; work PC: usually C:\Users\<you>\OneDrive\Dashboard\).
  3. First time on each computer: give it a short name (e.g. mac, workpc), then click the ⚠ Connect Data folder chip and pick Dashboard/Data. Allow edit access. Time then syncs both ways through OneDrive.
  4. GitHub sync (iPad, or computers without OneDrive): File → GitHub sync…, enter your private data repo and paste this device's own token (the dialog shows how to make it). Only encrypted files are sent. See Help → FAQ.
  5. The dashboard reads Data/inbox-snapshot.js (capital D) in that folder, copied there after each Inbox Exporter run. If it's missing you'll see the fictional example with an ⚠ EXAMPLE DATA badge.
  6. Check the As of stamp top right. Amber ⚠ Stale means the snapshot is more than 24 hours old.
  7. Click a total to filter the list; click it again (or Clear) to show everything.
  8. Log time with +15 / +30 / +60 / ⋯ on any line. Meeting time counts by itself; use Adjust under a meeting to change it. When two meetings overlap, press Attended? on the one you went to.
  9. Calls and chats you didn't schedule: + Log call (above the list), or write - [log] lines in your notebook log. They load by themselves from Data/notebook-log.js once it's synced, and File → Import notebook log… is the fallback.
  10. Print: File → Print my sheet… or Print Manager's sheet… (landscape, one page).

Help

Projects

The Projects tab is the source of truth for your projects, laid out like Planner: plans → buckets → tasks → checklists. + Plan, + Bucket and + Task add them; click a task to edit its title, bucket, owner, status, progress, priority, dates, labels, account, notes and checklist, or delete it. Owner: pick a name from the list or type any name (no email addresses); the list comes from projectOwners in config.local.js and names already used. No pricing or dollar figures: text with an amount isn't saved. Export CSV, Export xlsx and Export Graph JSON save Planner-ready files (Planner's export columns; Graph plannerPlan/plannerBucket/plannerTask/plannerTaskDetails shapes). Planner can't import CSV or xlsx files: the CSV and xlsx match the layout of Planner's own "Export plan to Excel", for Excel or an import tool. The Graph JSON is shaped for Microsoft Graph's Planner API (fields marked x_ are hints for the importer). Nothing is sent to Planner or Microsoft Graph. Exports are plain files and ask first when the Data folder is encrypted. Projects are saved encrypted in this browser and, once the Data folder is encrypted, as projects-store.json.enc in the Data folder (and GitHub hub); the newest save wins between computers. File → Import Planner export into Projects copies an encrypted projects.json.enc Planner export (optional). Print prints the list in the print colors.

Daily Focus

The home screen. Squares: Due Today (the ▲/▼ chip compares the snapshot's Due Today total with the previous business day's latest snapshot; Monday compares with Friday; it ignores items you mark Done here), Overdue, Waiting past due (Waiting on items whose due date, the check-back date, is today or earlier) and Going cold (★ key accounts with no touch in 14+ days). Sections, in order: Due Today, Overdue, Owed to outside (Follow-ups and Account touches you owe someone outside: the task has an account, or its person isn't on your internal-people list), Waiting · past check-back, Going cold · key, Travel ≤ 7 days, then Later this week (collapsed). About 12 rows show in total (focusRowCap in config.js); each section keeps at least one row, Due Today and Overdue at least three, and +n more opens the rest. Open items with no date are counted under the sections, and show a red ⚠ no date in Owed to outside and Going cold.

Done, Snooze and Log touch

✓ Done hides the row here (Undo for 8 seconds) and counts it in "n done here, not yet in To Do" until you tick it off in To Do. The dashboard never changes To Do: when a later snapshot shows the task done, the mark clears itself; if you edited the task in To Do after marking it, To Do wins and the row comes back ("reopened in To Do"). Snooze: Later today (+3 h), Tomorrow 8:00, Next Monday 8:00 or a date you pick; the due date doesn't change, and if To Do re-dates the task the snooze ends. Log touch opens + Log call with the account and person filled in (Phone, 15 min); it counts as a touch for Going cold. Stars, Done and Snooze sync between your computers inside your encrypted time file.

Key accounts and colors

☆/★ next to an account stars it as a key account (Focus rows, the Totals list, Workload). File → Key accounts & internal people… lists them all. On first run the dashboard offers to star your T1 accounts. Colors mean urgency only and always come with a word and an icon: ● Today green, ▲ Overdue red, hourglass Waiting amber, ◐ Cooling blue, ◆ This week ivory, ✈ Travel, ▸ Later grey.

Totals

Status row: Overdue, Due Today, This Week, I Owe, Owed to Me, Going Cold. To Do lists row: Follow-ups, Waiting on, Account touches, Travel. Each tile shows the count, the change from last week (▲ +n / ▼ −n / no change / n/a) and a small trend line. For Overdue, I Owe and Going Cold, a rise is shown in red. Hover a tile for its exact rule. Show trends opens all ten trend lines since the dashboard started.

Week over week

The current week's latest snapshot is compared with the previous week's latest snapshot. If the previous week has no snapshot, the nearest older week is used and marked *. With only one week of data you'll see n/a.

Going Cold

An open item with no activity in 14 or more days. Activity is the latest of: its To Do edit, time logged on that item (time on other items, calls or meetings doesn't count for it), or any meeting with its account (a meeting counts for every item on that account).

List

Grouped Overdue, Due Today, This Week (tomorrow through Sunday), Next. Each line is Person/account: action · Weekday M/D with its To Do list, account (T1 = top tier, ★ = your key account) and a status word. Click a line for details. ⚡ = quick win (15 min or less). ❄ = going cold. ⊘ Withheld = tagged Withhold in To Do: shown on your own screen and print sheet (marked [WITHHELD]), never on Manager's sheet. Your photo appears on screen only, not on printed sheets.

Calendar

Today and tomorrow, 7 AM–6 PM in this computer's time zone. Overlapping events get an amber outline and ⚠ Conflict.

Syncing between your computers

Each computer has a name and saves the time you log there in Data/time-<name>.json; it never writes another computer's file. Every computer reads all time-*.json files in Data (OneDrive conflict copies such as time-mac-Laptop2.json too) and merges them the same way, so both show the same totals. If the same entry was changed on both, the later change wins (same second: the alphabetically later machine name). The Data folder is checked every 60 seconds and when you come back to the tab. The sync chip (top right) shows the last sync and the machines seen; ⚠ means the folder isn't connected, needs your OK again (Reconnect), or a file couldn't be read (hover for which). Keep both computers' clocks set automatically: if a time stamp from a computer is more than 5 minutes in the future the chip shows ⚠ Clock ahead and names it. Changes you make after seeing such a stamp still count (the dashboard's clock always moves past the newest stamp it has seen). Browsers without folder access (e.g. Safari): use File → Save my time file… into Data and File → Open time files….

Time and workload

Time entries are never written to To Do; they sync between your computers through the Data folder (see above). Meeting time from the calendar counts in the totals right away; there's no pending step. Press Adjust under the meeting (or in Workload) to change minutes, audience, subject or account. Overlapping meetings fill no time until you press Attended? on one; only that meeting counts. Pick another to move the time, or choose Not attended in Adjust. Audience and subject are guessed (marked guessed, hover for why) from the attendee domains and title: internal domains → Internal - Domestic; international internal domains → Internal - International; a mapped account domain → its audience; otherwise Owner/operator. Subjects come from title words (training/webinar, software/product, design/review/submittal, travel/flight), otherwise Account strategy. When you change an audience, the dashboard remembers it for those domains.

Calls and chats (unscheduled)

Types: Phone, Teams chat, Teams call, Other. Use + Log call, or add lines to your notebook log (notebook-log.md) like
- [log] YYYY-MM-DD HH:MM | 20m | Channel | Audience | Subject | Account | Person | note
e.g. - [log] 2026-10-19 09:40 | 20m | Phone | Owner/operator | Technical/design support | Acme Fab | Priya M. | riser sizing question
Minutes can be 20, 20m, 1h or 1h15m. Channel is Phone, Teams chat, Teams call or Other. Audience, Subject, Account, Person and note may be left blank; a blank audience or subject is guessed (marked guessed). Person is a name only and must not contain "@". Dates and times must be real (e.g. no 25:99), and neither Person nor note may contain "@". Only lines that start with - [log] are read; every other line is ignored, and loading again won't duplicate entries.
Loading: after each Inbox Exporter run, tools/make_log_js.py on the box turns notebook-log.md into Data/notebook-log.js (only the - [log] lines). It's copied into Dashboard/Data/ in OneDrive and the dashboard loads it by itself. If it's missing, use File → Import notebook log… and pick notebook-log.md. Nothing ever changes, overwrites or git-ignores notebook-log.md; notebook-log.md isn't in the Dashboard folder at all.

Going Cold list

Under the item list, every going-cold item is listed with its last activity date and the number of days since, oldest first.

Clearing and exporting

File → Clear local data… clears trend history and the opened snapshot, and keeps your time entries. To delete time entries too, tick Also delete all time entries and type DELETE. File → Export time entries (CSV)… saves every entry (date, minutes, hours, source, type, audience, subject, account, task, event, title, note).

Not in this version

The By-account view, account-based Going Cold and the "My next three things" ranking are planned for later; the Proposed tray is hidden in v1.

Manager's sheet

Labelled "SANITIZED FOR MANAGER — no pricing, bid details or confidential details". Open items only, with no hours, calendar, Going Cold total, notes or mail. Items you tag Withhold in To Do never print. Inbox Exporter only passes the tag through and never sets it.

Removing time

Removing a meeting's time in Workload is remembered: it doesn't come back on reload. Press Removed · Count again under the meeting to count it again.

Example data in this browser

While the example is showing, time you log is kept only until you reload, so example entries never mix with your real ones.

FAQ

Which time zone does the dashboard use?

Always this computer's own, shown in the top bar (for example "CT · America/Chicago"); there is no setting. "Today", Due Today, Overdue, the 8:00 snooze return, meeting times and the "As of" stamp follow it. When you travel and the computer's clock changes zone, the dashboard notices within a minute (or when you come back to the window) and updates without reloading. A snooze you already set keeps its moment (8:00 CT is 7:00 MT). If the computer reports no zone, Central time is used.

Why did a done item come back?

The dashboard can't change To Do. A Done mark hides the row until the snapshot catches up. If the task was edited in To Do after you marked it (for example re-dated) and is still open, To Do wins and the row returns with "reopened in To Do".

What counts as a touch?

For Going cold · key: an outbound email, call, LinkedIn message or visit in the snapshot, a meeting with the account that has happened (from the calendar, or a proposed meeting once its date has passed), an edit to one of the account's To Do tasks, and any time you log with that account (Log touch, + Log call, a notebook log line). Emails they send you (inbound) don't count. ✓ Done doesn't count either.

What's Owed to outside?

Open Follow-ups and Account touches you owe (not started or in progress) that aren't already in Due Today or Overdue, where the task has an account or its person isn't on your internal-people list (File → Key accounts & internal people…).

Does a computer on the older version see my stars?

No. A 00.04 copy ignores stars, Done and Snooze marks (it keeps all time entries). Update every computer the same day.

How do I encrypt my Data folder?

Connect the Data folder, then File → Encryption…. Pick a passphrase (12+ characters) and save the recovery key it shows you somewhere off this computer. Every data file becomes <name>.enc (AES-256-GCM, encrypted in this browser) and a keyring.json holds the key, locked by your passphrase and by the recovery key. Plaintext originals are deleted after their encrypted copies are checked, unless you untick that.

I forgot my passphrase.

On the unlock screen choose Use recovery key, enter it and set a new passphrase. Without the passphrase or the recovery key the data can't be read by anyone, including you.

Is the browser's own cache encrypted?

Yes, once the Data folder is encrypted (00.03.001): the copy this browser keeps is stored encrypted with the same key, and nothing readable is cached while the app is locked. Exports (File → Export…) are plain on purpose and ask first.

What does "Remember on this computer" do?

It keeps the unlocked key in this browser (it can be used but not read out), so you aren't asked at every launch. Use File → Encryption… → Forget or Lock now to stop that.

Can I install it like an app?

Yes, when opened from its https address: in Edge use ⋯ → Apps → Install this site as an app (or Help → Install app…). It then opens in its own window and works offline. Opened as a file from disk it works as before, without install.

Why does it say EXAMPLE DATA?

Data/inbox-snapshot.js wasn't found, so the fictional example loaded. Check that it's in Dashboard/Data/ (capital D) and that OneDrive has synced the data folder.

Why is the As of stamp amber?

The snapshot is more than 24 hours old. The numbers may be out of date.

Does it change my To Do lists?

No. It only reads the snapshot. It writes only its own Data/time-<machine>.json.

Why don't I see the other computer's time yet?

OneDrive has to sync the file first (the work PC and Mac both need to be online), then the dashboard picks it up within 60 seconds. Check the sync chip lists both machine names.

What's time-mac-Laptop2.json?

A OneDrive conflict copy. The dashboard merges it with no duplicates; you can leave it or delete it once both computers have synced.

What does ⚠ Clock ahead mean?

Another computer's clock is more than 5 minutes fast. Your newer changes still win, but set that computer's clock to automatic. That computer shows ⚠ This computer's clock is ahead. Changes stamped more than 24 hours ahead (holdHours in config.js) are held: not applied, and they don't move the dashboard's clock, until real time reaches them.

Repair clock stamps (reset after a wrong clock)

1. On the computer named in the warning, set the date and time to automatic and check it's right. 2. Open the dashboard there and choose File → Repair clock stamps…. It re-stamps that computer's future-dated changes and places them right after the last change it stamped correctly, in their original order. Anything the other computer changed after that point still wins, and so does a change it made in the gap; that's the safe side. Each repaired change replaces its original by id, so an old OneDrive conflict copy (e.g. time-workpc-PC.json) that still holds the original future-stamped change is ignored — it can't bring it back, now or later; you can delete such copies once both computers show the same totals. The dashboard rewrites its own time-<name>.json and reloads. Nothing is deleted. 3. Wait for OneDrive to sync and the other computer to poll (about a minute). The warning then clears on both computers. Repair is refused while this computer's clock looks behind another computer's (a stamp or file time from it is more than 5 minutes ahead): repairing then would back-date your edits. Fix both clocks first. A repaired change is never placed before its meeting's start (or its date), so it still beats the other computer's automatic meeting time, and never later than now.

Can I import local data from the other computer?

No. File → Import local data… takes only this computer's own time events; events from other machines are ignored (the message says how many). The other computer's time arrives through its own file in Data.

Can two computers use the same name?

No. Give each its own name; the name can't be changed later from the app.

Is my data uploaded anywhere?

Only if you turn on File → GitHub sync…, and then only encrypted: the app sends .enc files and keyring.json to your own private GitHub repo and refuses anything else before it leaves the browser. Your passphrase and data key never leave your devices. Without GitHub sync there are no network calls; your files stay in Dashboard/Data/, and app updates never include a Data folder, so they can't overwrite them.

How do I set up GitHub sync on a computer?

1. Once, on github.com: create a private repo for the data (empty is fine). 2. On each computer: github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Name it after the computer, expiration 1 year (custom date), Resource owner = your account, Repository access = Only select repositories → the data repo, Repository permissions → Contents: Read and write (Metadata: Read is added by itself). Nothing else. 3. Copy the token (starts github_pat_), then in the dashboard File → GitHub sync…, enter owner/repo and paste it. The token is stored only in this browser, encrypted under your passphrase key. To cut off a lost device, delete its token on github.com; the other computers keep working.

Can I use it on an iPad?

Yes, through GitHub sync. Open the dashboard's https address in Safari (Share → Add to Home Screen to keep it), choose File → GitHub sync…, enter the repo and a token made for the iPad, then unlock with your passphrase. GitHub is the store there; there's no folder to connect.

What does the computer with the Data folder do with GitHub sync on?

The folder (e.g. OneDrive, or a local drive) stays the backup. Each sync copies encrypted files both ways: new files go where they're missing, this computer's own time file goes up, and everything else comes down from GitHub. Totals merge with the same rules as before.

GitHub says the token expired.

Make a new token for that computer (same steps) and paste it in File → GitHub sync…. Nothing else changes.

Why n/a on the week-over-week line?

There's no earlier week to compare yet.

Some rows were skipped (⚠ Incomplete)?

Those snapshot rows broke a rule (for example an unknown list). The banner lists them; the rest loaded.

Why didn't my overlapping meetings add time?

Overlaps fill nothing until you mark the one you attended.

Why does it read notebook-log.js instead of notebook-log.md?

A page opened as a local file can load a script but can't read a .md file by itself. So the box converts the - [log] lines into notebook-log.js. If that file isn't there, use File → Import notebook log….

Will my time entries survive a browser cache clear?

Yes, if the Data folder was connected: they're in Data/time-<machine>.json. You'll need to name the computer (use the same name) and reconnect the folder.
