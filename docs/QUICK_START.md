# Quick Start
1. Open `index.html` in your OneDrive `Dashboard` folder in Chrome or Edge (Mac: `<synced folder>/Dashboard/`; work PC: usually `C:\Users\<you>\OneDrive\Dashboard\`). Real data is read from `Dashboard/Data/` (capital D).
1a. First run on each computer: name it (`mac`, `workpc`), click **⚠ Connect Data folder**, pick `Dashboard/Data`, allow edit. Time syncs both ways via `Data/time-<machine>.json`.
1b. **Encrypt (00.03):** File → Encryption…, choose a passphrase (12+ characters), save the recovery key in your password manager and print a copy (Print…), tick the box, Continue. This browser's cache is encrypted too. "Remember on this computer" is ticked by default. If you're asked to delete the older version's copy, OK deletes it (only after it was checked). On the other computer: open, enter the same passphrase (tick Remember if you want). Lost passphrase: Use recovery key on the unlock screen.
1c. **Install (00.03):** from the https address in Edge: ⋯ → Apps → Install this site as an app. It installs as **Activity Dashboard**.
1d. **GitHub sync (00.04):** once, create a **private** repo for the data on github.com (empty). On each computer or iPad make its own fine-grained token (Settings → Developer settings → Personal access tokens → Fine-grained tokens: only the data repo, Contents: Read and write, 1-year expiry), then File → GitHub sync…, enter `owner/repo` and paste the token. Computers with a Data folder keep it as the backup; an iPad uses GitHub as its store (Safari → Share → Add to Home Screen). Only encrypted files go to GitHub.
2. **Daily Focus (00.05)** opens first: squares for Due Today (▲/▼ vs the previous business day), Overdue, Waiting past due and Going cold; click one to jump to its section. On a row: ✓ Done (Undo for 8 s; then tick it off in To Do), Snooze, Log touch. First time: confirm which T1 accounts to star as key accounts. Keys: j/k, d/s/t. Under the squares, **Today's Clear (00.05.003)** shows how much of today's and overdue work you've cleared (snoozed items are hatched and never count). Below them the **Today strip (00.06.000)** shows today's meetings, travel (with a leave-by time) and To Do deadlines; click a meeting for its details. File → Print Daily Focus… prints one landscape page. The other views are tabs (Totals is the former Dashboard). **Projects (00.07.000)** shows your Planner plans read-only; pick or type an owner, filter, Export CSV or print.
2a. Check "As of" (amber ⚠ Stale = older than 24 h). Times and "today" follow this computer's time zone (shown in the top bar, e.g. "CT · America/Chicago"); there's no setting, and it updates by itself when you travel (00.05.001).
3. Click a total to filter; click again to clear.
4. +15/+30/+60/⋯ on a line logs time. Meeting time counts by itself (Adjust to change); on overlaps press Attended? on the one you went to. + Log call for phone/Teams; `- [log]` lines from the notebook log load by themselves (Data/notebook-log.js); File → Import notebook log… is the fallback.
5. File → Print my sheet… / Print Manager's sheet… (landscape).
The full Help, How Do I, FAQ and Revision log are in the app's Help menu.
