# Quick Start
1. Open `index.html` in your OneDrive `Dashboard` folder in Chrome or Edge (Mac: `<synced folder>/Dashboard/`; work PC: usually `C:\Users\<you>\OneDrive\Dashboard\`). Real data is read from `Dashboard/Data/` (capital D).
1a. First run on each computer: name it (`mac`, `workpc`), click **⚠ Connect Data folder**, pick `Dashboard/Data`, allow edit. Time syncs both ways via `Data/time-<machine>.json`.
1b. **Encrypt (00.03):** File → Encryption…, choose a passphrase (12+ characters), save the recovery key in your password manager and print a copy (Print…), tick the box, Continue. This browser's cache is encrypted too. On the other computer: open, enter the same passphrase (tick Remember if you want). Lost passphrase: Use recovery key on the unlock screen.
1c. **Install (00.03):** from the https address in Edge: ⋯ → Apps → Install this site as an app.
2. Check "As of" (amber ⚠ Stale = older than 24 h).
3. Click a total to filter; click again to clear.
4. +15/+30/+60/⋯ on a line logs time. Meeting time counts by itself (Adjust to change); on overlaps press Attended? on the one you went to. + Log call for phone/Teams; `- [log]` lines from the notebook log load by themselves (Data/notebook-log.js); File → Import notebook log… is the fallback.
5. File → Print my sheet… / Print Manager's sheet… (landscape).
The full Help, How Do I, FAQ and Revision log are in the app's Help menu.
